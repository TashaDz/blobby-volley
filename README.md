# Blobby Volley — прототип

Переигровка классического Blobby Volley (Daniel Skoraszewski, 2000).
Один игрок против бота. Играть: https://tashadz.github.io/blobby-volley/

## Управление

- `←` / `→` — двигаться
- `↑` или пробел — прыжок
- `R` — новая партия
- `F1` — панель настройки физики (сила удара, желе, размеры, высота сетки)

Правила: rally scoring до 10 очков — очко даётся за каждый розыгрыш,
подача переходит к победителю. Больше трёх касаний одной стороной — потеря
розыгрыша.

Сделано на Unity 6.3, собрано под WebGL. Здесь лежит только билд.
